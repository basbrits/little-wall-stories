# Little Wall Stories V2 update

This update only replaces three files:

- index.html
- styles.css
- script.js

Do not delete or re-upload your assets folder. The new version uses the same image files already inside assets/.

## How to update on GitHub

1. Go to your repository.
2. Upload these three files to the main/root area of the repository.
3. When GitHub asks, choose to replace the existing files.
4. Click Commit changes.
5. Wait for GitHub Pages to redeploy.
6. Refresh your site with Ctrl+F5 or visit your domain with ?v=4 at the end.

Example:
https://littlewallstories.com?v=4

## What changed

- The landing section now immediately shows a product, price and add-to-cart button.
- The three product options are visible above the fold: Accent, Complete, Statement.
- The old oversized text sections and placeholder marketing copy were removed.
- The page is shorter, cleaner and more purchase-focused.
- Other themes are shown as simple browse cards, while Forest Friends remains the active launch product.
